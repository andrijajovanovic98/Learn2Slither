# ============================================================
#  Learn2Slither – Setup Guide
# ============================================================
#
#  1. Create a virtual environment (only once):
#       python3 -m venv env
#
#  2. Activate it:
#       Linux / macOS:   source env/bin/activate
#       Windows CMD:     env\Scripts\activate.bat
#       Windows PS:      env\Scripts\Activate.ps1
#
#  3. Install dependencies:
#       pip install -r requirements.txt
#
#  4. Run the program (from the project root):
#       python3 src/main.py --episodes 1000 --save src/models/qtable_1000.pkl
#
#  5. Run visually without loading a model (trains from scratch with display):
#       python3 src/main.py --visual --episodes 1000
#
#  6. Visual playback with a loaded model:
#       python3 src/main.py --visual --dontlearn --load src/models/qtable_2000.pkl

#  Deactivate the environment:
#       deactivate
# ============================================================
