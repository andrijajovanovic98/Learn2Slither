# ============================================================
#  Learn2Slither – Setup Guide
# ============================================================
#
#  1. Create a virtual environment (only once):
#       python3 -m venv env
#
#  2. Activate it:
#       Linux / macOS:   source env/bin/activate
#       Windows CMD:     env\Scripts\activate.bat
#       Windows PS:      env\Scripts\Activate.ps1
#
#  3. Install dependencies:
#       pip install -r requirements.txt
#
#  4. Run the program (from the src/ directory):
#       cd src
#       python3 main.py --episodes 1000 --save ../models/qtable_1000.pkl
#
#  5. Visual playback with a loaded model:
#       python3 main.py --visual --dontlearn --load ../models/qtable_1000.pkl
#
#  Deactivate the environment:
#       deactivate
# ============================================================
